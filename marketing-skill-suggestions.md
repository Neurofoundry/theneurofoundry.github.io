# Suggested New Skills

These are the next high-value skills to add if the product is moving toward prompt-driven browser automation and extension-based sales.

## 1. browser-extension-demo-builder

### Purpose

Turn a target workflow into a clean, persona-specific demo script and sales-ready mock output for browser extension use cases.

### Trigger

- "build a demo"
- "show this workflow"
- "make a sales walkthrough"
- "extension demo"

### Inputs

- persona
- target workflow
- desired output destination
- risk tolerance and approval points

### Outputs

- demo storyline
- prompt examples
- action graph
- approval checkpoints
- closing CTA for sales calls

### Why now

The project needs a repeatable way to turn product capability into buyer-ready demos without rebuilding the narrative from scratch every time.

## 2. extension-activation-funnel

### Purpose

Design and tune the path from first visit to extension install, access request, or guided pilot.

### Trigger

- "improve conversion"
- "activation funnel"
- "waitlist flow"
- "extension onboarding"

### Inputs

- page entry point
- CTA destination
- persona
- friction points

### Outputs

- funnel map
- copy recommendations
- form and CTA recommendations
- experiment list

### Why now

The current site has strong visuals but a diffuse conversion story. This skill would keep activation work focused and measurable.

## 3. buyer-objection-mapper

### Purpose

Generate objection handling for skeptical technical and operational buyers.

### Trigger

- "handle objections"
- "why would they say no"
- "sales enablement"
- "enterprise concerns"

### Inputs

- buyer type
- workflow
- deployment model
- pricing posture

### Outputs

- objection list
- response points
- proof requirements
- follow-up questions

### Why now

A browser automation product will face predictable objections around reliability, approvals, security, and scope control. This skill would speed up sales iteration.

## 4. proof-to-case-study

### Purpose

Turn product proofs, screenshots, workflow logs, and prototype output into tight case-study drafts.

### Trigger

- "make a case study"
- "turn this demo into proof"
- "write customer story"

### Inputs

- workflow summary
- metrics
- screenshots or local assets
- buyer persona

### Outputs

- case-study structure
- headline options
- before/after narrative
- quote prompts

### Why now

The repo already has proof-like material spread across product pages, reports, and visuals. This skill would help package that into sales assets.

## 5. competitive-teardown-browser-agents

### Purpose

Compare Neurofoundry's positioning against browser agent and AI browser competitors.

### Trigger

- "compare us to"
- "competitive teardown"
- "positioning gap"

### Inputs

- competitor names
- target persona
- use case

### Outputs

- positioning matrix
- messaging differences
- feature proof gaps
- landing-page angle recommendations

### Why now

If the product is truly aiming at a Comet-like browser market, competitive language needs to stay sharp and specific.

## 6. workflow-packaging-for-pilots

### Purpose

Take a raw browser automation idea and package it into a paid pilot offer.

### Trigger

- "scope a pilot"
- "package this workflow"
- "turn this into an offer"

### Inputs

- target workflow
- buyer team
- systems touched
- approval needs

### Outputs

- pilot scope
- implementation boundary
- success criteria
- rollout checklist

### Why now

The commercial path here is likely not extension-only. A repeatable pilot packaging skill would bridge product interest into services revenue.

## 8. sales-call-persona-router

### Purpose

Adapt the same product story to a founder, sales leader, recruiter, or ops buyer without rewriting everything manually.

### Trigger

- "tailor this pitch"
- "persona-specific demo"
- "rewrite for buyer"

### Inputs

- persona
- workflow
- deployment path
- strongest proof point

### Outputs

- call opener
- problem framing
- demo emphasis
- closing CTA

### Why now

The repo spans brand, product, and services. This skill would keep the message coherent while shifting emphasis for each buyer type.
