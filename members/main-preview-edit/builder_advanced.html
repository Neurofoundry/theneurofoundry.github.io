Builder Quick Help

  • Double-click element: Open style/animation panel
  • Shift+Click elements: Multi-select for grouping
  • Ctrl+D: Duplicate selected element
  • Delete: Delete selected element
  • Ctrl+ArrowUp/Down: Bring to front/send to back
  • Undo/Redo: Use toolbar or Ctrl+Z / Ctrl+Y
  • Snap to grid: Drag elements, auto-aligns to grid
  • Save/Load Prefab: Save or reuse custom elements
  • Emoji Bank: Insert fun emoji elements
  • Backdrop: Set background image or color
  • Group/Ungroup: Organize elements
  • Export: Save your design as clean HTML
