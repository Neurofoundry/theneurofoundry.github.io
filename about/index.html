What I Build

Software that respects the machine it runs on.

  • Local-first utilities Desktop tools, private workflows, and account-backed access where cloud services support the product without owning the whole experience.
  • Automation and operational systems Practical process automation, browser workflows, data handoffs, and small systems that remove repeated manual work.
  • Applied AI interfaces Interfaces and agent workflows designed around evidence, context, and real task completion.

How I Work

Build the working path first.
