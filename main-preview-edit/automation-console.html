Headed Playwright Automation

Translate plain language into visible browser action.

This console keeps a real browser open, accepts repeated natural-language commands, makes deterministic UI choices from accessibility metadata and CSS hooks, and advances the page step by step with deliberate human-speed delays.

Execution model

Single persistent browser session, queued commands, live event stream, no automatic browser close.

Element targeting

Role, label, placeholder, link text, aria-label, then CSS fallback from live page analysis.

Best fit commands

Navigation, search, login/signup, form fill, click/open/select, and follow-through submit steps.

Command

Each command is queued. The browser remains open so the next instruction can continue from the current page state.
